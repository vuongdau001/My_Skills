# Video Production — shared skills

## Canonical skill

[technical-animation-video-generator](technical-animation-video-generator/SKILL.md) builds vertical (9:16) technical explainer videos with Remotion, Vietnamese edge-tts voice-over and per-cue Vietsub. Method: real-world analogy first, then the technical mechanism, shown as simulations (packets travelling between nodes), not slides. Includes a script linter, per-cue TTS, frame QA tooling and a clean Remotion project template.

This repository is the canonical editable source. Commit and push changes here so other machines can pull the same version.
