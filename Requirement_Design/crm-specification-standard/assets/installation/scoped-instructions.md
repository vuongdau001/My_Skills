# CRM Spec Kit Scope

Artifacts in this directory use the CRM kit workflows. Read the installed kit INSTALL.md and project config `.agents/crm-spec-kit.json` from the repository root. Do not change source documents or shared repository instructions. Higher-priority workspace instructions still apply; surface conflicting requirements to the owner. Check/review workflows write records only. No automatic commit, push, ticket mutation or approval.

Use artifact_paths from the context bundle; missing layout in older configs means legacy. Do not rename project folders during install/update. Read the kit's knowledge-records-and-evidence reference when recording meetings/chat, decisions, assumptions or constraints. New knowledge records use metadata schema 2; legacy artifacts remain readable. Pin evidence and affected scope/revisions; a recorded discussion or action item is not authority approval or a product Task. lint --gate checks declared record obligations only, not full readiness or authenticity of approval.
